# Triangle_3D

Учебный проект HW3D: визуализация треугольников в OpenGL, поиск пересечений,
освещение и свободная камера. Полный вход: `0 < N < 1000000`, затем N троек
точек `(x, y, z)`. Принятое соглашение: касание считается пересечением.

## Сейчас реализовано

- `triangles_3d` читает сцену, запускает BVH и выводит маску пересечений
  из 0 и 1 в порядке входных фигур. Ошибки выводятся в stderr,
  программа завершается с ненулевым кодом.
  В библиотеке ввода `ReadPoint` читает три конечные координаты, проверяя
  запись числа целиком; поддерживаются дроби и научная запись.
  `ReadTriangle` читает три вершины по порядку, включая вырожденные фигуры;
  ошибки координат передаются вызывающему коду как исключения.
  `ReadScene` читает N и возвращает массив из N треугольников;
  неполная сцена и ошибки ввода приводят к исключению.
- `window_demo` показывает один треугольник с заданными в коде координатами.
  Красный цвет постоянный и пока не связан с пересечениями.
- `BuildRenderVertices` подготавливает три вершины с цветом на каждый
  треугольник: пересекающиеся красные, остальные синие. Порядок и координаты
  сохраняются; при разных размерах сцены и маски выбрасывается исключение.
  Подготовка выделена в библиотеку `triangle_render_data` и проверяется без окна.
- Библиотека геометрии содержит точки, векторы, отрезки, треугольники и AABB;
  реализованы базовые операции, длина, нормализация, нормали, площадь и границы.
  `BoundsOverlap` проверяет пересечение корректных AABB, включая касания
  и боксы нулевой толщины.
  `MergeBounds` строит общий охватывающий бокс двух корректных AABB.
  `ClassifyTriangle` различает точку, отрезок и невырожденный треугольник
  по совпадению вершин и устойчивым знакам ориентации трёх проекций.
  `DegenerateTriangleSegment` возвращает крайние исходные вершины
  вырожденной фигуры; точка представляется отрезком нулевой длины.
  `PointOnSegment(Point3, Segment3)` проверяет принадлежность точки отрезку
  в 3D, включая концы и отрезок нулевой длины, без допуска epsilon.
- В 2D реализованы ориентация точек, принадлежность точки отрезку и
  треугольнику, пересечения отрезков и треугольников. Граница включается,
  касания считаются пересечением. Геометрические решения используют
  адаптивный предикат знака `Orient2DSign` вместо сравнения приближённого определителя.
- В 3D реализованы расстояние со знаком до плоскости, проекции, сечения
  и проверка пересечения двух треугольников, включая общую плоскость.
  Копланарность, отсечение и выбор рёбер сечения используют `Orient3DSign`.
  Точки пересечения ребра с плоскостью вычисляются по двум согласованным
  значениям определителя без построения единичной нормали.
  `PointInTriangle(Point3, Triangle3)` проверяет принадлежность плоскости
  и проекции треугольника; граница включена, вырождение в точку/отрезок учтено.
  `SegmentsIntersect` и `SegmentIntersectsTriangle` поддерживают 3D-отрезки,
  в том числе нулевой длины. Общая `TrianglesIntersect` обрабатывает все
  сочетания точек, отрезков и обычных треугольников; касания включены.
- `FindIntersectionsBruteForce` возвращает маску: элемент `i` показывает,
  пересекается ли треугольник `i` хотя бы с одним другим. Перебор пар
  имеет сложность O(N²) и служит эталоном для небольших сцен.
- `BuildBvh` строит бинарное дерево боксов; `BuildNode` рекурсивно делит
  диапазоны индексов до листьев с максимум четырьмя треугольниками.
  `SplitAxis` выбирает наиболее протяжённую ось бокса.
  `BoxCenterCoordinate` вычисляет координату центра по выбранной оси.
  `CenterLess` сравнивает индексы по центрам боксов; группы больше четырёх
  элементов разделяются в `indexes` по медианной позиции через `std::nth_element`.
  Внутренние узлы хранят индексы потомков.
  `FindBvhCandidates` обходит дерево для бокса запроса и собирает индексы
  из пересекающихся листьев; среди кандидатов возможны лишние фигуры.
  `FindIntersectionsBvh` строит дерево и возвращает маску пересечений:
  каждая пара рассматривается один раз, после отбора кандидатов проверяются
  боксы пары и вызывается `TrianglesIntersect`. `BvhSearchStats` содержит
  число пар-кандидатов (`candidate_pairs`) и вызовов проверки треугольников
  (`exact_checks`); счётчики сбрасываются при каждом запуске.
  В плотных сценах число проверок может оставаться O(N²).
- Все проверки загрузчика, геометрии и подготовки вершин проходят (491 тест).

Проверки факта пересечения используют устойчивые знаки ориентации и
проекции без вычисления округлённых точек сечения или единичной нормали.
Отдельные `SegmentPlaneIntersection` и `TrianglePlaneIntersection`
строят приближённые координаты сечения; общая проверка их не вызывает.
`Orient2DSign` и `Orient3DSign` отклоняют NaN/бесконечности. Разброс двоичных порядков
ненулевых координат в одной проверке ограничен 256; при превышении
выбрасывается `std::range_error`.
При вычислении пары значений для отрезка применяется общий для обеих
точек масштаб отдельно по каждой оси; ограничение 256 порядков проверяется
внутри каждой оси. Проверка треугольника, задающего плоскость, использует
`Orient2DSign` и сохраняет его ограничения.

Загрузка сцены в визуализатор, связь результатов
с отрисовкой, кубический объём, освещение и камера ещё предстоят.

## Зависимости

Компиляторы C и C++17, CMake 3.16+, GLFW 3.3+, поддержка OpenGL 3.3 Core
и графический дисплей (для WSL — WSLg). GLAD включён в `third_party/glad`;
GoogleTest загружается CMake при первой сборке тестов, нужен интернет.
Арифметический код [Shewchuk](https://www.cs.cmu.edu/~quake/robust.html)
включён в `third_party/robust_predicates` (public domain) и собирается автоматически.
Локальная правка границ чтения массивов описана в
[заметке о зависимости](third_party/robust_predicates/README.md).

Для Ubuntu/WSL:

```bash
sudo apt update
sudo apt install build-essential cmake libglfw3-dev libgl1-mesa-dev
```

## Сборка и запуск

Все команды выполняются из корня проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/window_demo
```

Откроется окно с красным треугольником. Завершение — кнопкой закрытия окна.
Версия OpenGL выводится в терминал, диагностика ошибок — в stderr.

Проверка консольного поиска пересечений:

```bash
./build/triangles_3d < data/intersections.in
```

Ожидаемый вывод: `1 1 0` с новой строки. Первые два треугольника
пересекаются, третий расположен отдельно.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Проверяются границы N, пустой и некорректный ввод, переполнение
и сохранение следующих данных в потоке. Геометрические тесты проверяют
векторные операции, нормали, площади и границы треугольников, а также
принадлежность и пересечения в 2D и 3D: касания, вложение, совпадение,
сечения и перестановки вершин. Для маски проверяются пустой набор,
одиночная фигура, группы пересечений и перестановки входного набора.
Отдельно проверяются почти коллинеарные и почти копланарные конфигурации,
большие и малые масштабы, некорректные входы предикатов и использование
их знаков в геометрических проверках.
Для сечений добавлены регрессии потери компоненты нормали, общего масштаба
двух значений, малой доли отрезка у конца и перестановок вершин.
Графику эти автоматические тесты не проверяют.
Поиск через BVH сравнивается с полным перебором на фиксированных и случайных
сценах с постоянным seed, включая перестановки, касания и вырожденные фигуры.
Проверяются отсечение пар, отсутствие повторных проверок и сброс статистики.
Тесты подготовки вершин проверяют цвета, порядок, пустые и несовместимые
входы, вырожденные фигуры и цепочку чтение сцены → BVH → цветные вершины.

## Замеры BVH

`bvh_benchmark` сравнивает полный перебор с BVH на разнесённых фигурах,
отдельных пересекающихся парах и плотной группе совпадающих треугольников.
В каждом прогоне маски сравниваются; несовпадение завершает программу с ошибкой.
Измеряется медиана после одного прогрева; время BVH включает построение дерева,
подготовку боксов и поиск. Создание сцены и сравнение масок в замер не входят.

```bash
cmake -S . -B /tmp/triangle3d-release -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build /tmp/triangle3d-release --target bvh_benchmark -j2
/tmp/triangle3d-release/bvh_benchmark 512 3
```

Аргументы — число треугольников и повторов; результат выводится в CSV.
Для коротких учебных замеров установлены пределы 4096 фигур и 9 повторов.
Сохранённые результаты и параметры: [отчёт](results/bvh/report.md).
На разнесённых сценах дерево отсекает группы; при перекрытии всех боксов
остаётся O(N²) пар и дополнительные расходы на дерево.

## Организация

`include/` — интерфейсы, `src/` — реализации и программы,
`tests/` — тесты, `third_party/` — код зависимостей, `notes/` — учебные заметки.
Ввод и геометрия выделены в библиотеки; `window_demo` — отдельная программа;
результат поиска пересечений — признак для каждого треугольника.
