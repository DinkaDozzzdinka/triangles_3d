# Triangle_3D

Учебный проект HW3D: визуализация треугольников в OpenGL, поиск пересечений,
освещение и свободная камера. Полный вход: `0 < N < 1000000`, затем N троек
точек `(x, y, z)`. Принятое соглашение: касание считается пересечением.

## Сейчас реализовано

- `triangles_3d` читает и проверяет только количество треугольников.
- `window_demo` показывает один треугольник с заданными в коде координатами.
  Красный цвет постоянный и пока не связан с пересечениями.
- Библиотека геометрии содержит точки, векторы, отрезки, треугольники и AABB;
  реализованы базовые операции, длина, нормализация, нормали, площадь и границы.
- В 2D реализованы ориентация точек, принадлежность точки отрезку и
  треугольнику, пересечения отрезков и треугольников. Граница включается,
  касания считаются пересечением. Проверки с треугольниками пока рассчитаны
  на невырожденные фигуры; численная устойчивость требует отдельной доработки.
- Все 138 тестов загрузчика и геометрии проходят.

Чтение координат сцены, поиск пересечений в 3D, кубический объём, освещение
и управление камерой ещё предстоит добавить.

## Зависимости

Компиляторы C и C++17, CMake 3.16+, GLFW 3.3+, поддержка OpenGL 3.3 Core
и графический дисплей (для WSL — WSLg). GLAD включён в `third_party/glad`;
GoogleTest загружается CMake при первой сборке тестов, нужен интернет.

Для Ubuntu/WSL:

```bash
sudo apt update
sudo apt install build-essential cmake libglfw3-dev libgl1-mesa-dev
```

## Сборка и запуск

Все команды выполняются из корня проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/window_demo
```

Откроется окно с красным треугольником. Завершение — кнопкой закрытия окна.
Версия OpenGL выводится в терминал, диагностика ошибок — в stderr.

Проверка консольного загрузчика:

```bash
printf '2\n' | ./build/triangles_3d
```

Ожидаемый вывод: `Triangle3D started`, затем `2` с новой строки.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Проверяются границы N, пустой и некорректный ввод, переполнение
и сохранение следующих данных в потоке. Геометрические тесты проверяют
векторные операции, нормали, площади и границы треугольников, а также
принадлежность и пересечения в 2D: касания, вложение, совпадение и
перестановки вершин. Графику эти автоматические тесты не проверяют.

## Организация

`include/` — интерфейсы, `src/` — реализации и программы,
`tests/` — тесты, `third_party/` — код зависимостей, `notes/` — учебные заметки.
Ввод и геометрия выделены в библиотеки; `window_demo` — отдельная программа;
результат поиска пересечений — признак для каждого треугольника.
