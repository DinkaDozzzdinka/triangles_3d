## Triangle_3D

Программа на вход получает число 0 < N < 1000000. Это количество наборов точек (координаты x, y, z) треугольника (плоские в 3-х мере). Потом задаются эти N наборов. 

Программа должна выводить кубический объем с помощью OpenGL. Должно быть освещение и пересекающиеся треугольники должны подсвечиваться красным. Камера должна летать по объему.

**Принятое соглашение: касание общей точкой или отрезком считается пересечением.**

Программа должна быть разделена на следующие части (проект разделим на модули):
1) чтение данных со стандартного ввода
Получает   - поток входных данных.
Возвращает - коллекцию треугольников или сообщение об ошибке.
2) определение пересечения треугольников
Получает   - коллекцию треугольников.
Возвращает - Признак для каждого треугольника, пересекается ли он с каким-либо другим треугольником.
3) отрисовка экрана
Получает   - треугольники и признаки пересечения.
Возвращает - Управляет камерой, освещение, показывает кубический объем.
4) main (свяжет 1-3)

Т.о. если мы поменяем способ отрисовки, то нам придется отредактировать только реализацию 3-ей части.

Хранить все пересекающиеся пары не будем, это займет много памяти
